# 만약에 쇼츠: 채널 기획서

## 1. 한 줄 컨셉
> **"한국 사람이라면 무조건 공감하는 '만약에'를, 물음표 고양이 '만냥이'가 60초 안에 끝까지 시뮬레이션해 준다."**

## 2. 이미 포화된 영역 (피할 것)
| 포화된 유형 | 대표 예시 | 피하는 이유 |
|---|---|---|
| 우주·지구 재난형 | 지구가 자전을 멈춘다면, 달이 사라진다면, 태양이 꺼진다면 | 해외·국내 대형 채널이 수년간 다룸 |
| 인체 3D 해부형 | ○○을 먹으면 몸에서 생기는 일 (3D 인체 애니) | 비슷한 3D 인체 쇼츠가 매우 많음 |
| AI 브레인롯·캐릭터 패러디 | 유명 만화 캐릭터 AI 영상 | 저작권 위험 + 수익화 거절 위험 |
| 단순 "가정 질문 + 스톡 영상 + AI 음성" | — | 유튜브 '반복·대량 생산 콘텐츠' 정책에 걸리기 쉬움 |

## 3. 우리 채널의 차별점
1. **한국 일상에서만 나오는 소재**: 배달앱, 수능, 지하철, 편의점, 회식, 조선시대
2. **고정 캐릭터 '만냥이'**: 매 편 같은 캐릭터가 상황 속으로 들어가 직접 겪음 → 채널의 얼굴
3. **실제 숫자 1개 이상**: 무게, 비용, 시간 같은 계산을 보여줘서 '그냥 상상'이 아닌 '시뮬레이션'으로 만들기
4. **고정 엔딩**: "여러분이라면? 댓글로 👇" + 다음 편 예고 한 줄

### 캐릭터 설정: 만냥이
- 생김새: 통통한 크림색 고양이, 머리 위에 노란 물음표 모양 털 한 가닥, 파란 후드티
- 성격: 호기심 많고 겁 많음. 매번 "만약에…?" 하고 일을 벌였다가 수습함
- **AI 이미지 고정 프롬프트** (매 컷 앞에 붙이기):
  `a chubby cream-colored cat character with a single yellow question-mark-shaped tuft of hair on its head, wearing a blue hoodie, 3D Pixar-style, soft lighting, vertical 9:16`

## 4. 영상 공통 구조 (45~60초)
| 구간 | 시간 | 역할 | 연출 |
|---|---|---|---|
| 훅 | 0~2초 | 질문 자막 크게 + 충격 장면 | 클로즈업, 빠른 줌인, 효과음 |
| 1단계 | 2~15초 | 처음 벌어지는 일 | 미디엄 샷, 만냥이 반응 |
| 2단계 | 15~35초 | 일이 커짐 (숫자·계산 등장) | 와이드 샷, 인포그래픽 자막 |
| 반전 | 35~50초 | 예상 못 한 결말 | 정적 → 갑자기 컷 전환 |
| 엔딩 | 50~60초 | "여러분이라면?" + 다음 편 예고 | 만냥이 정면 클로즈업 |

## 5. 제작 파이프라인 (움직이는 그림 만들기)
| 단계 | 할 일 | 추천 도구 (택1) |
|---|---|---|
| ① 대본 | 이 저장소의 `scripts/` 대본 사용 | Claude |
| ② 이미지 | 콘티의 영문 프롬프트로 컷별 이미지 생성 | ChatGPT 이미지, Midjourney, Ideogram |
| ③ 움직임 | 이미지를 3~5초 영상으로 변환 (image-to-video) | Kling, Runway, Google Veo, Pika |
| ④ 목소리 | 내레이션 TTS (가능하면 본인 목소리 녹음이 수익화에 유리) | 타입캐스트, ElevenLabs, 클로바더빙 |
| ⑤ 편집 | 컷 배치, 자막, 효과음, BGM, 줌·흔들림 효과 | CapCut, Vrew |
| ⑥ 업로드 | 유튜브 쇼츠 + 인스타 릴스 동시 업로드 | 각 앱 |

### 구도·카메라 용어 (프롬프트·편집에 그대로 사용)
- **익스트림 클로즈업** (`extreme close-up`): 눈·손·물건. 충격과 감정 강조, 훅에 사용
- **클로즈업** (`close-up`): 얼굴. 반응 컷
- **미디엄 샷** (`medium shot`): 허리 위. 행동 설명
- **와이드 샷** (`wide shot`): 장소 전체. 규모가 커질 때
- **버드아이 뷰** (`top-down bird's-eye view`): 도시·군중·숫자 비교
- **로우 앵글** (`low angle`): 압도감, 거대한 것
- **움직임**: `slow zoom in`(긴장), `quick whip pan`(장면 전환), `camera shake`(충격), `dolly out`(규모 공개)

## 6. 수익화 체크리스트
- [ ] 매 편 실제 정보·계산이 들어갔는가
- [ ] 만냥이가 등장하고 채널 고유의 말투가 있는가
- [ ] 저작권 있는 캐릭터·음악·영상을 쓰지 않았는가 (BGM은 유튜브 오디오 보관함 등 무료 음원)
- [ ] AI로 만든 사실적인 장면이면 업로드 시 'AI 생성/변경 콘텐츠' 표시
- [ ] 같은 틀을 그대로 복사하지 않고 매 편 다른 장면 구성을 썼는가

## 7. 주제 후보 (30개)
**한국 일상**: 배달앱이 24시간 멈춘다면 / 수능이 없어진다면 / 지하철이 1주일 멈춘다면 / 편의점이 모두 사라진다면 / 회식이 법으로 금지된다면 / 한국에 겨울이 사라진다면 / 모든 아파트 엘리베이터가 멈춘다면 / 카톡이 하루 꺼진다면 / 치킨값이 1만 원 고정이라면 / 출퇴근이 순간이동이라면

**돈·숫자**: 1원짜리로 월급을 받는다면 / 하루 1만 원씩 100년 모은다면 / 로또 1등이 매주 내게 온다면 / 모든 물건값이 1000원이라면 / 세금이 0원이라면

**역사 IF**: 조선시대에 스마트폰이 있었다면 / 세종대왕이 한글을 안 만들었다면 / 조선에 배달앱이 있었다면 / 이순신 장군에게 드론이 있었다면 / 신라 시대에 유튜브가 있었다면

**만냥이 몸 실험**: 고양이가 회사를 다닌다면 / 사람이 고양이처럼 하루 16시간 잔다면 / 30일 동안 물만 마신다면 / 한 달 동안 말을 안 한다면 / 하루가 48시간이라면

**황당 시뮬레이션**: 한국인 전원이 동시에 점프한다면 / 서울에 비가 1년 동안 내린다면 / 모든 사람의 키가 2배라면 / 반려동물이 말을 할 수 있다면 / 거짓말하면 코가 길어진다면
