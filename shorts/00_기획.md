# 만약에 쇼츠: 채널 기획서

## 1. 한 줄 컨셉
> **"당연했던 것이 사라지거나, 말도 안 되는 일이 벌어진 순간부터 몇 년 뒤까지를 내레이션으로 따라간다."**

## 2. 형식
- **내레이션 100%**: 등장인물 대사 없음. 채널 주인이 직접 녹음 (수익화에도 유리)
- **타임라인 구조**: 사건 발생 → 0초 → 몇 분 → 몇 시간 → 며칠 → 몇 달 → 몇 년
- **화면**: 사건의 결과를 보여주는 장면 (도시, 사람들, 사물, 자연). 화면 구석에 **타임라인 표시** 고정 (예: `⏱ 3초 후`)
- **길이**: 60~90초

### 영상 공통 구조
| 구간 | 역할 | 연출 |
|---|---|---|
| 훅 (0~3초) | "지금 이 순간, ○○이 사라진다면?" | 일상 장면 → 한순간에 변화, 화면 흔들림 |
| 즉시 (0초~1분) | 가장 먼저 눈에 보이는 변화 | 클로즈업, 빠른 컷 |
| 단기 (몇 시간~며칠) | 사회가 반응하기 시작 | 와이드 샷, 도시 전경 |
| 장기 (몇 달~몇 년) | 세상이 바뀐 모습 | 위에서 내려다보는 샷, 느린 카메라 |
| 반전·엔딩 | 예상 못 한 결말 + 시청자 질문 | 정적 → 마지막 한 줄 |

## 3. 주제 고르는 기준 (4개 중 3개 이상 통과해야 채택)
1. **듣자마자 "어? 그러면 어떻게 되지?"가 떠오르는가**
2. **연쇄 반응이 있는가**: 하나가 사라지면 그 다음, 또 그 다음이 무너지는 구조
3. **그림이 되는가**: 화면으로 보여줄 장면이 떠오르는가
4. **근거가 있는가**: 과학이나 사실로 설명할 부분이 있는가 (100% 공상은 탈락)

### 버리는 주제 (예시와 이유)
| 주제 | 탈락 이유 |
|---|---|
| 서울 지하철이 갑자기 사라진다면 | 결과가 뻔함 (막힌다, 버스 탄다). 연쇄 반응 없음 |
| 택시기사가 우리나라에 없다면 | 상상할 거리가 없음. 그림이 안 됨 |
| 배달앱이 멈춘다면 | 결과가 "불편하다"에서 끝남 |
| 모든 사람의 그림자가 사라진다면 | 아무 일도 안 일어남 |
| 외계인이 쳐들어온다면 | 근거 없는 100% 공상 |

### 이미 너무 많은 주제 (중복이라 피함)
- 산소가 5초 동안 사라진다면 / 중력이 5초 사라진다면 / 마찰력이 사라진다면
- 지구 자전이 멈춘다면 / 달이 사라진다면 / 태양이 꺼진다면
- 인류가 사라진다면 (인류 멸망 후 지구) / 전 인류가 동시에 점프한다면

## 4. 제작 파이프라인
| 단계 | 할 일 | 도구 |
|---|---|---|
| ① 대본 | `scripts/` 대본 사용 | Claude |
| ② 장면 생성 | 장면 묘사를 붙여넣어 영상 생성 | CineForge AI 등 |
| ③ 내레이션 | 직접 녹음 | 휴대폰 녹음 / CapCut 녹음 |
| ④ 편집 | 타임라인 표시, 자막, 효과음, BGM | CapCut, Vrew |
| ⑤ 업로드 | 유튜브 쇼츠 + 인스타 릴스 | 각 앱 |

### 구도·카메라 용어 (장면 묘사에 그대로 사용)
- **익스트림 클로즈업**: 사물 하나에 집중 (사라지는 순간)
- **와이드 샷**: 도시·거리 전체 (규모가 커질 때)
- **버드아이 뷰**: 위에서 내려다보기 (몇 년 뒤 바뀐 세상)
- **로우 앵글**: 무너지는 큰 구조물
- **움직임**: 천천히 줌인(긴장), 빠른 화면 전환(시간 점프), 화면 흔들림(충격), 뒤로 빠지기(규모 공개)

## 5. 수익화 체크리스트
- [ ] 직접 녹음한 내레이션인가
- [ ] 사실·과학 근거가 1개 이상 들어갔는가 (업로드 전 확인)
- [ ] 저작권 있는 음악·영상·브랜드를 쓰지 않았는가
- [ ] AI로 만든 사실적인 장면이면 업로드 시 'AI 생성/변경 콘텐츠' 표시
- [ ] 이전 편과 같은 장면 구성을 복사하지 않았는가
- [ ] 재난 장면은 잔인하거나 자극적으로 묘사하지 않았는가
