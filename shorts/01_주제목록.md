# 주제 목록

## 원칙
- **주제는 넓게, 사례는 구체적으로.** 주제는 전 세계 누구나 바로 상상할 수 있는 것으로 잡고, 장소와 사람은 대본 안의 사례에서 구체화한다
- 두 가지 유형만 다룬다
  - **A. 사소한 것 → 재앙**: 너무 당연해서 신경도 안 쓰던 것이 사라지거나 바뀌면 세상이 무너진다
  - **B. 황당한 사건**: 말은 안 되지만 "그러면 진짜 어떻게 되지?"가 궁금해진다
- 기획서의 기준(궁금증, 연쇄 반응, 그림, 근거) 4개 중 3개 이상 통과
- ⭐ = 먼저 만들 추천 주제
- "대표 사례"는 대본에서 중심 긴장선으로 쓸 만한 장면

## A. 사소한 것 → 재앙
| 주제 | 대표 사례 (아슬아슬한 장면) | 연쇄 반응 |
|---|---|---|
| ⭐ 전 세계의 나사와 볼트가 1분 동안 사라진다면 | 송전탑 정비공의 안전고리 | 의자 → 송전탑 → 정전 → 다리 |
| ⭐ 세상의 모든 끈과 줄이 1분 동안 사라진다면 | 번지점프 뛰기 직전 / 엘리베이터 안 | 신발끈 → 크레인 → 엘리베이터 와이어 → 현수교 케이블 |
| ⭐ 전 세계의 배터리가 한순간에 방전된다면 | 비행 중인 비행기 조종석 | 휴대폰 → 자동차 시동 → 병원 장비 → 통신 |
| ⭐ 전 세계의 자물쇠가 한순간에 모두 열린다면 | 동물원 맹수 우리, 은행 금고 | 현관문 → 금고 → 교도소 → 동물원 |
| 세상의 모든 유리가 사라진다면 | 고층 빌딩 유리창 청소부, 고속도로 위 자동차 앞유리 | 안경 → 창문 → 스마트폰 → 빌딩 외벽 |
| 지구의 모든 접착제가 사라진다면 | 결혼식 중 신랑 구두 밑창 | 신발 → 가구 → 스마트폰 화면 → 책 |
| 세상의 모든 고무가 사라진다면 | 비 오는 고속도로의 자동차 타이어 | 타이어 → 신발 밑창 → 수도관 패킹 |
| 세상의 모든 철이 1분 만에 녹슨다면 | 놀이공원 관람차 꼭대기 | 못 → 자동차 → 철도 → 철골 건물 |
| 모든 콘크리트가 모래로 돌아간다면 | 아파트 20층에서 저녁 먹던 가족 | 보도블록 → 다리 → 댐 → 빌딩 |
| 바퀴가 세상에서 사라진다면 | 이륙하려고 활주로를 달리는 비행기 | 캐리어 → 자동차 → 비행기 → 시계 톱니 |
| 단추와 지퍼가 하루 동안 사라진다면 | 면접장, 결혼식 (코믹) | 출근길 대혼란 → 옷핀 품절 |
| 세상의 모든 신호등이 하루 동안 꺼진다면 | 출근길 사거리 한가운데 버스 | 교차로 → 출근 대란 → 구급차 |

## B. 황당한 사건
| 주제 | 대표 사례 | 왜 궁금한가 |
|---|---|---|
| ⭐ 지구의 모든 물이 1시간 동안 젤리가 된다면 | 수영장에서 다이빙하던 사람, 샤워 중인 사람 | 강, 바다, 수도관, 그리고 몸속 물은? |
| ⭐ 모든 곤충이 강아지만큼 커진다면 | 캠핑장 텐트, 아파트 베란다 | 개미, 모기, 바퀴벌레… 생태계와 공포 |
| ⭐ 하늘에서 1시간 동안 비 대신 탄산수가 내린다면 | 우산 없이 퇴근하던 직장인 | 거품 홍수, 금속 부식, 식물 반응 |
| 세상의 모든 소리가 10배 커진다면 | 도서관에서 누가 재채기, 공항 활주로 옆 | 경적, 아기 울음, 귀 건강, 도시 마비 |
| 모든 고양이가 사자 크기가 된다면 | 집사의 침대 위 | 귀여움 vs 공포, 사료값, 아파트 |
| 세상의 모든 바람이 하루 동안 멈춘다면 | 바다 위 요트, 풍력발전소 | 공기 정체, 미세먼지, 비행기, 날씨 |
| 비가 아래가 아니라 위로 내린다면 | 우산 쓴 사람, 농부 | 강이 마르고, 하늘에 물이 쌓인다 |
| 지구의 하루가 갑자기 25시간이 된다면 | 알람 맞춰 둔 출근길 | 시계, 수면, 위성, 달력 |
| 전 인류가 잠을 잘 수 없게 된다면 | 고속버스 기사, 관제탑 | 24시간, 3일, 1주일마다 몸과 사회가 무너짐 |
| 모든 사람의 키가 갑자기 2배가 된다면 | 비행기 좌석, 엘리베이터 안 | 문, 자동차, 식량, 심장 부담 |

## C. 버린 주제
| 주제 | 이유 |
|---|---|
| 서울 지하철이 사라진다면 | 결과가 뻔함 |
| 택시기사가 없다면 | 상상할 거리가 없음 |
| 배달앱이 멈춘다면 / 카톡이 꺼진다면 | "불편하다"에서 끝남 |
| 그림자가 사라진다면 | 아무 일도 안 일어남 |
| 특정 지역 한정 주제 (예: 서해가 밀려온다면) | 주제가 너무 좁아짐. 한국 장소는 대본 속 사례로만 쓰기 |
| 산소·중력·마찰력이 5초 사라진다면 | 이미 너무 많음 |
| 지구 자전·공전이 멈춘다면, 달·태양이 사라진다면 | 이미 너무 많음 |
| 외계인이 쳐들어온다면 | 근거 없는 100% 공상 |
