## A. 당연했던 것이 잠깐 사라진다면
| 주제 | 스케일 | 왜 재밌나 (연쇄 반응) |
|---|---|---|
| ⭐ 전 세계의 나사와 볼트가 1분 동안 사라진다면 | 사소한 것 → 재앙 | 의자, 안경부터 송전탑, 다리까지. 1분 뒤 돌아와도 이미 다 분해됨 |
| ⭐ 세상의 모든 색이 1시간 동안 사라진다면 | 중간 | 신호등, 약 구분, 익은 과일, 전선 색 구분이 전부 불가능 |
| ⭐ 지구의 모든 접착제가 사라진다면 | 사소한 것 → 재앙 | 신발 밑창, 합판 가구, 스마트폰 화면, 책 제본, 붕대 |
| 전 세계의 소리가 10분 동안 사라진다면 | 중간 | 사이렌, 화재경보, 경적이 무용지물. 사람들이 손짓으로 소통 |
| 모든 거울과 반사가 사라진다면 | 큰 스케일 | 자동차 미러, 망원경, 그리고 빛 반사로 신호를 보내는 광케이블 인터넷까지 |
| 지구에서 금이 한순간에 사라진다면 | 큰 스케일 | 반도체 회로, 금니, 각국 금 보유고, 금값 폭등 |
| 전 세계 냉장고가 일주일 동안 멈춘다면 | 중간 | 음식뿐 아니라 백신, 혈액, 수산물 유통까지 |
| 바닷물에서 소금이 하룻밤 사이 사라진다면 | 큰 스케일 | 바다 생물, 해류, 날씨까지 바뀜 |
| 지구에서 모래가 사라진다면 | 큰 스케일 | 콘크리트, 유리, 반도체(실리콘)를 못 만듦 |
| 하룻밤 사이 전 세계 반도체가 사라진다면 | 큰 스케일 | 자동차, 병원, 은행, 비행기 관제 |
| 바퀴가 세상에서 사라진다면 | 사소한 것 → 재앙 | 자동차, 캐리어, 의자, 시계 톱니바퀴까지 |
| 단추와 지퍼가 하루 동안 사라진다면 | 사소한 것 (코믹) | 출근길 대혼란, 옷핀 품절 |
| GPS 위성이 하루 동안 꺼진다면 | 큰 스케일 | 길 찾기뿐 아니라 시간 동기화를 쓰는 금융, 통신까지 |

## B. 재앙급 / 황당한 사건이 일어난다면
| 주제 | 스케일 | 왜 재밌나 |
|---|---|---|
| ⭐ 전 인류가 잠을 잘 수 없게 된다면 | 큰 스케일 | 24시간, 3일, 1주일마다 몸과 사회가 무너지는 과정 (실제 연구 근거 있음) |
| ⭐ 하늘에서 1시간 동안 비 대신 탄산수가 내린다면 | 황당 | 거품 홍수, 금속 부식, 식물 반응 |
| 지구의 하루가 갑자기 25시간이 된다면 | 중간 | 시계, 수면 리듬, 위성 궤도, 달력 |
| 하룻밤 사이 전 세계 언어가 하나로 통일된다면 | 큰 스케일 | 번역가, 외국어 학원, 여행, 외교 |
| 모든 사람의 키가 갑자기 2배가 된다면 | 황당 | 문, 자동차, 비행기 좌석, 식량, 심장 부담 |
| 지구 자기장이 하루 동안 사라진다면 | 큰 스케일 | 오로라가 서울에서도 보임, 철새, 위성 고장 |
| 모든 모기가 한순간에 사라진다면 | 중간 | 질병 감소 vs 생태계 먹이사슬 |
| 전 세계 바다가 1m 낮아진다면 | 큰 스케일 | 항구, 섬, 새로 드러나는 땅 |
