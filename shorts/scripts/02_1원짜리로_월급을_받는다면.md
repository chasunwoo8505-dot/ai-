# EP02. 만약 월급을 전부 1원짜리 동전으로 받는다면?

- 길이: 약 55초 / 화면비 9:16
- 제목(유튜브): 월급 300만 원을 1원짜리로 받으면 무게가…? 😱
- 제목(릴스 첫 줄): 월급을 1원짜리로 받으면 생기는 일
- 해시태그: #만약에 #월급 #1원 #쇼츠 #만냥이 #돈
- 캐릭터 고정 프롬프트 = `[만냥이]`

## 계산 근거 (자막에 사용)
- 1원 동전 무게: **약 0.729g** (한국은행 화폐 정보 기준, 업로드 전 재확인)
- 월급 300만 원 = 1원 동전 **3,000,000개**
- 3,000,000 × 0.729g = **2,187kg ≈ 2.2톤**
- 비교: 경차 1대 약 0.9~1톤 → **경차 2대 이상 무게**
