# EP01. 만약 전 세계의 나사와 볼트가 1분 동안 사라진다면?

- 길이: 약 90초 / 화면비 9:16 / 내레이션만
- 제목(유튜브): 전 세계 나사가 딱 1분만 사라진다면? 🔩
- 제목(릴스 첫 줄): 나사가 1분 사라지면 생기는 일
- 해시태그: #만약에 #나사 #상상 #쇼츠 #과학 #타임라인
- 톤: 평범한 오후로 시작 → 사례마다 긴장 → 1분 뒤 안도 → 가볍게 웃기는 엔딩

## 이 대본의 규칙
- **사례 하나 = 상황(누가·어디서·무엇을) → 순간 → 결과**
- 🎬 **화면**은 무슨 일이 벌어지는지 보여주고, 🎙 **내레이션**은 화면으로 알 수 없는 것(이유, 숫자, 다음에 올 일)만 말한다
- 🔇 표시된 순간은 내레이션 없이 효과음만
- 다치거나 피 나는 장면 없이 **아슬아슬하게** (유튜브 광고 제한 피하기)
- 처음 등장한 사람들은 엔딩에서 다시 보여준다

## 등장 사례
| 사례 | 장소 | 상황 |
|---|---|---|
| ① 부장님 | 여의도 회의실 | 회의 결론을 내리며 의자 등받이에 기대는 중 |
| ② 송전탑 정비공 | 산 위 송전탑 40m 지점 | 안전고리를 볼트에 걸고 작업 중 |
| ③ 버스 승객들 | 한강 철교 위 버스 | 퇴근길, 졸고 있는 학생 |
| ④ 수술실 | 대학병원 | 수술 중 |
| ⑤ 아이 | 아파트 2층 침대 | 낮잠 자는 중 |
| ⑥ 풍력발전기 | 제주 바닷가 | 사람 없음 (규모를 보여주는 장면) |

> ⚠️ 볼트로 연결된 구조물이 실제로 얼마나 버티는지는 구조마다 다릅니다. "흔들린다, 기운다, 떨어질 뻔한다" 수준으로 썼습니다. 병원 비상발전기는 실제로 정전 시 자동으로 켜지는 설비입니다.
